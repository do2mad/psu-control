## Description (max. 4000)
PSU Control remote-controls the UNI-T UDP3305S-E programmable bench power supply over your local network. The interface recreates the instrument's front panel – display, soft keys and buttons – so you feel at home right away. Interface in German.

MEASURE AND SET
• Live voltage, current and energy (Wh) or power (W) of all channels
• CV/CC indication, switch outputs individually or all at once
• Set voltage and current with the keypad or in small steps
• Set and enable over-voltage and over-current protection (OVP/OCP)
• Independent, series and parallel mode
• CH3 quick select 1.8 / 2.5 / 3.3 / 5 V

WAVE – CURVE VIEW
• History of voltage, current and power of all channels
• Time axis 30 seconds, 2 minutes or 10 minutes

LIST AND DELAYER
• Voltage and current sequences with up to 2048 steps
• Templates: sine, pulse, ramp/triangle, staircase, exponential or your own table
• Preview, upload, start/stop and progress display
• Timed output on/off with stop condition – ideal for endurance tests and power-up sequencing

PRESET, STORAGE AND UTILITY
• Read, edit and apply preset groups P1–P5
• Memory slots 1–10
• Beeper, brightness, key and remote lock, LAN settings, RS-232, error queue, self-test

CONNECT
• Network search finds the instrument automatically
• Manual IP entry and recently used devices
• Built-in simulator to try everything without an instrument
• SCPI console for your own commands

PRIVACY
PSU Control only talks to the power supply in your local network. No accounts, no tracking, no ads, no data sent to the internet.

REQUIREMENTS
UNI-T UDP3305S-E with LAN enabled, on the same network (SCPI over TCP port 5025). Other models of the UDP3000S series use the same commands.
